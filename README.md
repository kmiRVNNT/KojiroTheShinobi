# 🥷 Kojiro the Shinobi  
### *Unity Web Game — In Development*  

**Kojiro the Shinobi** is a web-based action game built in **Unity**, inspired by a long-lost title once hosted on **Kongregate**.  
Recreated from scratch, the game focuses on fast-paced combat and fluid movement, where players click to move and strike enemies with precise, directional slashes.  

---

## ⚔️ Gameplay Concept  

Players control **Kojiro**, a lone shinobi fighting waves of enemies.  
Using a simple *click-to-move* and *click-to-attack* system, each slash targets the player’s cursor position — rewarding timing, positioning, and spatial awareness.  

---

## 🧠 Development Details  

- 🧩 **Built with:** Unity (C#)  
- ⚙️ **Mechanics:** Custom click-to-move pathing, directional slashing, and enemy behavior scripting  
- 🚀 **Focus:** Performance optimization and smooth, responsive controls  
- 🧪 **Status:** Unfinished prototype (not published)
